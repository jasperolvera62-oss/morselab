📖 WHAT IS MORSE CODE?

Morse code turns letters, numbers and punctuation into patterns of short (· dot) and long (− dash) signals. Each character has its own unique pattern — E is a single dot, T is a single dash. Everything else is built from those two units. In audio, a dot lasts one unit of time, a dash three; gaps separate them.
